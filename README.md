# E-commerce 🛒

Aplicação de e-commerce desenvolvida com HTML, CSS e JavaScript durante minha formação em Desenvolvimento Front-End na Kenzie Academy Brasil, em 2022.

O projeto simula uma loja virtual com catálogo de produtos e carrinho de compras, utilizando JavaScript puro para criação dinâmica dos elementos e gerenciamento das interações do usuário.

## Funcionalidades

- Exibição de catálogo de produtos
- Renderização dinâmica dos produtos no DOM
- Adição de produtos ao carrinho
- Remoção individual de produtos
- Contador de itens no carrinho
- Cálculo e atualização do valor total da compra
- Atualização dinâmica do estado visual do carrinho
- Exibição de mensagem para carrinho vazio

## Estrutura

Os dados dos produtos são armazenados localmente em JavaScript e utilizados para gerar dinamicamente os cards da vitrine.

A lógica principal da aplicação é responsável pela criação dos produtos, gerenciamento do carrinho, atualização da quantidade de itens e cálculo do valor total da compra.

## Desenvolvimento

Durante o desenvolvimento, utilizei uma branch específica para as funcionalidades do carrinho de compras, posteriormente integrada ao projeto por meio de Pull Request.
